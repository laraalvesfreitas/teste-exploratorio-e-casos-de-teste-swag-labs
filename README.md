#  Teste Exploratório - Swag Labs


## 📌 Sobre o projeto
Este repositório contém a execução de testes exploratórios no sistema Swag Labs, um e-commerce utilizado para prática de testes de software.

Site: https://www.saucedemo.com/

Durante a exploração da aplicação, foram identificados comportamentos inesperados e possíveis falhas.  
Com base nisso, foram elaborados casos de teste funcionais para documentar, reproduzir e validar os erros encontrados.



##  Objetivo
- Explorar o sistema sem roteiro pré-definido
- Identificar falhas e comportamentos inconsistentes
- Documentar bugs encontrados
- Criar casos de teste para reprodução dos problemas



##  Tipos de teste aplicados
- Teste exploratório
- Teste funcional (validação das funcionalidades)



##  Principais problemas encontrados
- Possibilidade de concluir compra sem produtos no carrinho
- Usuário bloqueado não consegue realizar login (comportamento esperado validado)
- Problemas ao remover produtos do carrinho
- Falhas ao adicionar determinados produtos



##  Estrutura do repositório
- `/casos-de-teste` → Casos de teste criados com base nos cenários encontrados  
- `/bugs` → Relatos de bugs identificados  
- `/evidencias` → Prints ou registros dos erros encontrados  



##  Ferramentas utilizadas
- Navegador Web
