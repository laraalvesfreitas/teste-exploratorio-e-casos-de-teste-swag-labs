## Bug Report — Lentidão nas ações de navegação com usuário de baixa performance


**ID do Bug:** BUG-007 

**Título:** Usuário performance_glitch apresenta lentidão nas ações de navegação e interação  

**Módulo:** Navegação / Produtos / Carrinho  
**Ambiente:** Web (Desktop)  
**URL:** https://www.saucedemo.com/  

---

### Pré-condição  
Usuário logado com o perfil **performance_glitch_user**.

---

### Descrição  
O sistema apresenta lentidão significativa em diversas ações de navegação e interação ao utilizar o usuário *performance_glitch_user*. As respostas das ações não ocorrem de forma imediata, prejudicando a experiência do usuário.

---

### Passos para reprodução  
1. Acessar o sistema  
2. Fazer login com o usuário **performance_glitch_user**  
3. Navegar entre as páginas do sistema  
4. Realizar ações como:
   - Clicar no botão "Back"
   - Clicar no botão "Continue Shopping"
   - Utilizar filtros na página Products  

---

### Resultado esperado  
As ações de navegação e interação devem ocorrer de forma rápida e responsiva, sem atrasos perceptíveis.

---

### Resultado obtido  
As ações apresentam atraso significativo para serem executadas:
- O botão "Back" demora para retornar à página Products  
- O botão "Continue Shopping" demora para redirecionar  
- A funcionalidade de filtro demora para responder  
- Botões de navegação apresentam lentidão ao retornar para páginas anteriores
