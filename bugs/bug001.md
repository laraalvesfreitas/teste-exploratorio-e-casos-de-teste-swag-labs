## Bug Report

Finalizar compra sem itens no carrinho

ID do Bug: BUG-001
Título: Usuário consegue finalizar compra sem produtos no carrinho

Módulo: Checkout / Carrinho
Ambiente: Web (Desktop)
URL: https://www.saucedemo.com/

Descrição: 
O sistema permite que o usuário finalize uma compra mesmo sem possuir produtos no carrinho, o que viola a regra básica de negócio de um e-commerce.

Passos para reprodução: 
1. Acessar o sistema
2. Não adicionar nenhum produto ao carrinho
3. Navegar até o checkout
4. Tentar finalizar a compra

Resultado esperado: 

O sistema deve exibir uma mensagem de erro informando que não é possível finalizar a compra sem itens no carrinho.

Resultado obtido: 

A compra é finalizada com sucesso e a mensagem de agradecimento é exibida ao usuário.
