## Bug Report — Problemas de layout na aplicação com usuário visual_user

**ID do Bug:** BUG-013  
**Título:** Usuário visual_user apresenta inconsistências visuais em múltiplas páginas da aplicação  

**Módulo:** UI / Layout  
**Ambiente:** Web (Desktop)  
**URL:** https://www.saucedemo.com/  

---

### Pré-condição  
Usuário logado com o perfil **visual_user**.

---

### Descrição  
A aplicação apresenta inconsistências visuais ao utilizar o usuário *visual_user*. Elementos da interface estão desalinhados e mal posicionados em diferentes páginas, comprometendo a experiência do usuário.

---

### Passos para reprodução  
1. Acessar o sistema  
2. Fazer login com o usuário **visual_user**  
3. Navegar entre as páginas da aplicação (Products, Carrinho, Checkout)  
4. Observar o layout dos elementos  

---

### Resultado esperado  
O layout deve estar consistente e organizado em todas as páginas, com elementos alinhados corretamente e seguindo o padrão visual do sistema.

---

### Resultado obtido  
A aplicação apresenta problemas visuais em múltiplas telas, como:  
- Botões desalinhados  
- Elementos sobrepostos ou fora de posição  
- Layout inconsistente entre páginas

### Severidade

---

### Observação  
O problema ocorre apenas com o usuário *visual_user*, indicando possível falha de renderização ou aplicação de estilos específica para esse perfil.
