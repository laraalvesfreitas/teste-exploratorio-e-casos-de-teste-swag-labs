## Bug Report — Permite avançar sem preencher "Last Name"

**ID do Bug:** BUG-012
**Título:** Sistema permite avançar no checkout sem preencher o campo "Last Name" com usuário error_user  

---

### Pré-condição  
Usuário logado com **error_user**

---

### Descrição  
O sistema permite avançar para a etapa Overview sem preencher um campo obrigatório.

---

### Passos  
1. Login com **error_user**  
2. Iniciar checkout  
3. Deixar "Last Name" vazio  
4. Clicar em continuar  

---

### Resultado esperado  
Sistema deve bloquear avanço e exibir erro  

---

### Resultado obtido  
Usuário avança normalmente
