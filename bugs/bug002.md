Bug Report — Remover produto do carrinho

ID do Bug: BUG-002
Título: Usuário problem_user não consegue remover produto do carrinho

Módulo: Produtos / Carrinho
Ambiente: Web (Desktop)
URL: https://www.saucedemo.com/

Pré-condição: 

Usuário logado com o perfil problem_user.

Descrição: 

O sistema não permite que o usuário problem_user remova produtos do carrinho a partir da página de produtos (Products), o que viola o comportamento esperado de um e-commerce.

Passos para reprodução: 

1. Acessar o sistema
2. Fazer login com o usuário problem_user
3. Adicionar um ou mais produtos ao carrinho
4. Na página Products, clicar no botão "Remove" de um produto

Resultado esperado: 

O produto deve ser removido do carrinho e o botão deve voltar ao estado "Add to cart".

Resultado obtido: 

O produto permanece no carrinho mesmo após clicar no botão "Remove".

Evidências: 

https://github.com/user-attachments/assets/247377b5-7f57-430c-8a2e-6f6dc0281b64



Severidade: 

Alta — Impacta diretamente a funcionalidade do carrinho para um tipo de usuário.

Prioridade: 

Alta — Deve ser corrigido com urgência.

Observação: 

O problema não ocorre com outros tipos de usuário, indicando possível falha específica de permissão ou comportamento associado ao perfil problem_user.
