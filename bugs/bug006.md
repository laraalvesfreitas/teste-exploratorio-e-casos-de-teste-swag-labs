## Bug Report — Falha ao preencher o campo "Last Name" no checkout

**ID do Bug:** BUG-006  
**Título:** Usuário problem_user não consegue preencher o campo "Last Name" no checkout  

**Módulo:** Checkout / Formulário de informações  
**Ambiente:** Web (Desktop)  
**URL:** https://www.saucedemo.com/  

---

### Pré-condição  
Usuário logado com o perfil **problem_user** e com pelo menos um produto no carrinho.

---

### Descrição  
O sistema apresenta falha ao tentar preencher o campo "Last Name" durante o processo de checkout com o usuário *problem_user*. O campo não aceita entrada corretamente, impedindo o avanço no fluxo de compra.

---

### Passos para reprodução  
1. Acessar o sistema  
2. Fazer login com o usuário **problem_user**  
3. Adicionar um produto ao carrinho  
4. Acessar o carrinho e iniciar o checkout  
5. Tentar preencher o campo "Last Name"  

---

### Resultado esperado  
O campo "Last Name" deve aceitar a entrada de dados normalmente, permitindo que o usuário prossiga no checkout.

---

### Resultado obtido  
O campo "Last Name" não aceita o preenchimento corretamente, impedindo a continuidade do processo de checkout.
