Bug Report — Falha ao adicionar produtos ao carrinho com problem_user

ID do Bug: BUG-003
Título: Usuário problem_user não consegue adicionar alguns produtos ao carrinho

Módulo: Produtos / Carrinho
Ambiente: Web (Desktop)
URL: https://www.saucedemo.com/

Pré-condição: 

Usuário logado com o perfil problem_user.

Descrição: 

O sistema apresenta falha ao tentar adicionar determinados produtos ao carrinho utilizando o usuário problem_user. Nem todos os produtos são adicionados corretamente, o que compromete a funcionalidade básica de compra.

Passos para reprodução: 

1. Acessar o sistema
2. Fazer login com o usuário problem_user
3. Na página Products, tentar adicionar diferentes produtos ao carrinho
4. Observar o comportamento ao clicar no botão "Add to cart"
   
Resultado esperado: 

Todos os produtos selecionados devem ser adicionados corretamente ao carrinho.

Resultado obtido: 

Três produtos não são adicionados ao carrinho mesmo após clicar no botão "Add to cart".

Evidências: 


https://github.com/user-attachments/assets/8fb96d40-82ea-433c-8c9e-5ae411cd55e5



Severidade: 

Alta — Impacta diretamente a funcionalidade principal do sistema.

Prioridade: 

Alta — Deve ser corrigido com urgência.

Observação: 

O problema ocorre apenas com o usuário problem_user, indicando possível comportamento inconsistente entre perfis de usuário.
